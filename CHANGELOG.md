# Changelog

All notable changes to Awesome Omarchy Themes are documented here.

The project follows [Semantic Versioning](https://semver.org/) for tagged repository releases. Theme additions and maintenance work accumulate on `main`; maintainers cut releases from a green, reviewed `main`.

## [Unreleased]

No unreleased changes yet.

## [0.1.0] - 2026-09-09

First public release.

### Added

- 12 complete Omarchy themes, split evenly across dark and light modes.
- Dark themes: Hermes Bloodline, Hermtang, Nous Noir, Portal Vibes, Green Magic, and The Perfect Computer.
- Light themes: Hermachy, Nous DayShift, Roseglass, Codexy, Claudey, and Tonarchy.
- Per-theme palettes, redistributable backgrounds, real applied-theme previews, icon-theme selections, contrast data, compatibility notes, and artwork licensing/source documentation.
- Reusable `omarchy-theme-maker` skill with palette extraction, contrast reporting, preview-capture guidance, and agent-safe workflow documentation.
- Deterministic repository validator with regression tests, real image decoding, contrast checks, README/theme index synchronization, and repository hygiene checks.
- GitHub Actions validation on every pull request and pushes to `main`.
- Contributor guide, agent operating contract, security policy, code of conduct, issue templates, and pull request template.
- README hero artwork, project/maintainer badges, X Money funding link, and release documentation.

### Safety and quality

- Theme contributions are intentionally restricted to color/theme assets; executable theme code, terminal overrides, and full `shell.toml` overrides are rejected by repository policy.
- Main-branch rules prevent deletion and force-pushes and require pull requests with review-thread resolution.
- Wallpaper and preview assets are validated structurally and with a real decoder before merge.
